habits.css содержит только общую оболочку всего раздела Habits V2.
habitsMain.css содержит только импорты внутренних файлов пустого состояния.
layout.css отвечает только за контейнер пустой страницы.
content.css содержит дату, заголовок и подзаголовок.
addButton.css содержит кнопку + и её состояния.
responsive.css содержит только адаптив пустой страницы.
В index.html подключены правильные входные файлы модулей.
